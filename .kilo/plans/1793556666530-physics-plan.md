# Plan: Physics improvements for arena mode

## Goal
Add ricochet, knockback, and stacking physics to arena mode.

## Scope
- Arena only (`godot/scripts/action.gd`).
- Quiz mode untouched.

## Decisions
- All physics interactions: ricochet, knockback, stacking.

## Implementation steps
1. Convert hazards to RigidBody3D with collision.
2. Add projectile ricochet (max 2 bounces).
3. Add knockback on player hit.
4. Add ice block props (RigidBody3D) that stack.
5. Cap rigid bodies for performance.

## Validation
- Run gen_test, play_test, rebuild exe, push source (no exe).

## Risks
- Physics may affect performance; cap rigid bodies.
